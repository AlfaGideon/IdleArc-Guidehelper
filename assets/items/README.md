# Иконки предметов (assets/items)

Сюда складываются **настоящие игровые картинки предметов** — по одной на каждый тир и ранг
просыпания (Item Codex → Appearance). Каталог пустой: файлы появляются после загрузки.

Как получить картинки:

1. **Кнопка в приложении** — «Скачать игровые картинки через браузер» (шаг 4 «Что надеть»).
   Картинки скачивает ваш браузер и передаёт приложению; работает, даже если у сервера нет интернета.
2. **Скрипт на машине с интернетом** — `node scripts/fetch-art.mjs` (скачает всё разом в этот каталог).
3. **Кнопка «Скачать игровые картинки»** — серверный вариант для машин с интернетом.

После загрузки рядом появляется `index.json` — карта «семейство → иконки по тирам».
Пока файлов нет, приложение рисует предметы собственными SVG-иконками, чтобы карточки
были узнаваемыми и без интернета.
