# Иконки предметов (assets/items)

Сюда складываются **настоящие игровые картинки предметов** — по одной на каждый тир и ранг
просыпания (Item Codex → Appearance). Каталог пустой: файлы появляются после загрузки.

Как получить картинки (шаг 4 «Что надеть» → панель «Картинки предметов»):

1. **«Скачать игровые картинки»** — универсальная кнопка. Сначала пробует сервер
   (работает, если у машины с сервером есть интернет); если сервер выйти в сеть не смог —
   автоматически скачивает всё вашим браузером и передаёт файлы серверу
   (`POST /api/art/upload` → сюда). Работает и локально, и в онлайн-превью.
2. **«Скачать через браузер на сервер»** — то же, что п.2 универсальной кнопки, но без
   попытки качать сервером. Нужна, когда сервер точно без интернета (превью, sandbox).
3. **«Скачать в папку проекта»** (Chrome/Edge) — браузер пишет файлы НАПРЯМУЮ в эту
   папку (File System Access API): сервер вообще не участвует, работает даже на
   статическом хостинге вроде GitHub Pages. Один раз выберите этот каталог.
4. **Скрипт на машине с интернетом** — `node scripts/fetch-art.mjs`.

Что внутри конвейера: Item Codex (`data/item_codex_data.json`) тянется напрямую, а при
блокировке CORS — через открытые прокси (corsproxy → codetabs → allorigins; картинки —
ещё и через images.weserv.nl). Скачивание идёт пулом в 4 потока с одним автоповтором
недостающих файлов: ~250 иконок занимают пару минут. Источник — хост компаньона
(idlearc.com часто отвечает 403 и идёт последним).

После загрузки рядом появляется `index.json` — карта «семейство → иконки по тирам».
Пока файлов нет, приложение рисует предметы собственными SVG-иконками, чтобы карточки
были узнаваемыми и без интернета.
