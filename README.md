# IdleArc Guide Helper

Веб-приложение (SPA без зависимостей), которое помогает **правильно собрать персонажа в IdleArc** — под класс, уровень и цель игры. Все данные — снапшот официальных источников: сайт игры `idlearc.com` (включая официальные патч-ноты 1.3.1 «Season 2: The Forge» и страницу классов) и открытая IdleArc Wiki.

> Это неофициальный фанатский инструмент. Он не подключается к аккаунту игры, не автоматизирует геймплей и не требует логина.

## Что умеет

- **Планировщик сборки.** Выбираете класс (Warrior, Archer, Mage, Rogue, Druid), уровень и цель (прогресс, фарм, боссы, пет-билд, Retaliation) — приложение:
  - **распределяет классовые очки по всем трём веткам** с учётом правил игры (1 очко на 1 уровне + 1 каждые 3 уровня; Tier 2 — после 5 очков в ветке, Tier 3 — после 10; требования между навыками). Доли ветвей зависят от цели: минимум 1 очко в каждую, остальное — пропорционально весам цели, затем сильные ветки «доводятся» до Tier 2/3. Одинаковых планов на разные цели не бывает, и для каждой ветки есть объяснение «почему столько очков»;
  - **учитывает +All Class Skills** (Torch, Sage Diadem, легендарные петы) отдельной панелью: ползунок 0…25, таблица прироста по каждому стат-эффекту и предупреждение там, где сработал кап навыка. Эффективный ранг = вложенные очки + бонус, и он виден у каждого навыка в дереве (гейты ветвей при этом считаются только по вложенным очкам);
  - даёт **ручной режим**: кнопки «+»/«−» у каждого навыка мгновенно пересчитывают бонусы, а валидатор подсвечивает превышение максимума, превышение доступных очков, закрытые тиры и невыполненные требования;
  - показывает итоговые бонусы (AD%, крит, Double Hit/Damage, пет, фарм-статы) и предупреждения (например, что данные Druid официально не описаны);
  - выдаёт **отдельный блок «Экипировка»** — по каждому из 10 слотов: семейство предмета и его имя, имплисит (и его диапазон по тирам), до 4 рекомендованных аффиксов (только совместимые с семейством), целевые Drop Bonuses и гем для этого слота, плюс пометку, если слот занят двуручным оружием;
  - выдаёт **отдельный блок «Гемы»** — семья гема для каждой слот-группы (оружие / Torch / броня / украшения), эффект гема в этом слоте, целевая редкость по уровню, таблица вторичных статов с отметкой приоритета и порядок работы с сокетами;
  - выдаёт приоритет характеристик, талисманы и состав петов;
  - экспортирует план текстом (для Discord) и кодом сборки, который можно передать другому игроку.
- **Калькуляторы.** Урон (крит >100% → Crit Damage, «полные сотни» Double Hit/Double Damage, Boss Damage, Shadow Echo), защита (софт-кап DR 95% / хард-кап 99%, минимум 1% урона), Retaliation (`Reflecting% × Defense`, блок +50%), значение гема, стоимость Mastery, компоунд петов, классовые очки.
- **Кодекс.** Поиск и фильтры по классу и слоту; каталог всех 40 семейств из Item Codex (имена по тирам T1→T6/A1, имплисит по тирам, совместимые аффиксы, условие выпадения) + аффиксы, Drop Bonuses (T2→T9), гемы и сокеты, классовые навыки, талисманы и инскрипты, петы, статы и стойки, Mastery, ML-анлоки, биомы, Convergence, гильдия, смена класса.
- **Нюансы и источники.** Список ловушек билдостроения (капы, диминишинг Lucky, баланс компоунда петов, `Slayer's` только для боссов и т.д.) + список источников и явная маркировка «подтверждено / требует проверки».

## Запуск

```bash
node server.js            # http://localhost:5173  (PORT=8080 node server.js — другой порт)
```

Сервер без зависимостей (только Node.js ≥ 18). Приложение — статика, поэтому подойдёт любой статический хостинг (GitHub Pages, Netlify, `python3 -m http.server`).

## Тесты

```bash
node tests/smoke.mjs
```

Обновление в браузере: сервер отдаёт файлы с `Cache-Control: no-store` и меткой сборки (`/api/build`, поле `build` в `src/data/systems.js`, отображается в шапке). Если у вас открыта старая сборка, вверху появится баннер с кнопкой «Обновить сейчас» — она перезагружает приложение в обход кэша. При изменении данных не забудьте поднять `DATA_META.build` и `?v=` у скрипта в `index.html` (совпадение проверяется тестом).

Смоук-тест прогоняет рендер всех вкладок через лёгкий DOM-шим и проверяет: планировщик по 5 классам × 5 целям × 5 уровням, использование всех трёх ветвей, отличие планов разных целей, работу +All Class Skills (прирост бонусов и непревышение капов), непрохождение Tier-гейтов от +All, валидацию ручного режима, план экипировки и гемов (10 слотов, соответствие семейству/статам цели), целостность каталога предметов, коды сборок и формулы (крит >100%, DR-капы, Retaliation, гемы, компоунд петов, Mastery).

## Структура

```
index.html                 — каркас SPA и вкладки
server.js                  — статический сервер без зависимостей
styles/app.css             — тёмная тема в стиле игры (цвета редкостей из Item Codex)
src/app.js                 — роутинг вкладок
src/data/classes.js        — 5 классов, все классовые навыки: значения за очко, капы, требования
src/data/items.js          — Item Codex: 40 семейств с именами по тирам и имплиситами T1–T6, аффиксы, Drop Bonuses T2–T9, гемы, сокеты, таблица дропа по ML
src/data/systems.js        — статы, атрибуты, стойки, Mastery, петы, талисманы, руны, гильдия, прогрессия
src/data/builds.js         — профили рекомендаций: стойки, приоритеты статов, веса навыков, правила экипировки по слоту/цели, гем-конфигурации, карта «стат → аффикс»
src/core/calc.js           — формулы игры и модели расчёта
src/core/planner.js        — распределение очков по ветвям, эффекты +All Class Skills и капы, план экипировки/гемов, валидация, экспорт/импорт кодов
src/ui/*.js                — экраны: планировщик, калькуляторы, кодекс, нюансы
docs/RESEARCH.md           — конспект исследования официальных источников и выводы
tests/smoke.mjs            — смоук-тесты
```

## Откуда цифры: официальные данные и «оценки»

- **Официальные параметры игры:** правила очков и тиров, значения большинства классовых навыков, аффиксы и их роллы, Drop Bonuses T2–T9 (со шкалами по тирам), гемы (формула и таблицы), петы (шансы, pity, капы компоунда), талисманы, Mastery, ML-анлоки, Convergence, Guild Skill Tree, изменения патча 1.3.1.
- **Пометка «оценка» (значок у навыка + подпись в тултипе):** там, где точная формула в игре не опубликована, значение не берётся с потолка и не ждёт, пока кто-то выложит цифры. Считаем по механике игры: берём ближайший известный параметр — аналогичный навык другого класса, Drop Bonus с его шкалой по тирам или подтверждённую формулу (например, Retaliation = Reflecting% × Defense) — и выводим оценку. Таких навыков сейчас 19: 18 навыков Druid (ветки/тиры восстановлены по тематике) и Warrior-навык `Counterstrike`. У каждого в данных есть поле `estimateNote` с указанием аналога, а в интерфейсе — значок «оценка».
- **Модель, а не официальная формула:** расчёт ожидаемого множителя удара (крит >100%, «полные сотни» DH/DD, капы DR). Порядок слоёв урона игра не раскрывает, поэтому цифры годятся для сравнения вариантов, но не как точный DPS.
- **Заменить оценку на точные цифры:** одна строка на навык в `src/data/classes.js` (`perPoint`, `cap`), после чего можно удалить `estimated: true` и `estimateNote`.
