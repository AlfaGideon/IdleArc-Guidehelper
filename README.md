# IdleArc Guide Helper

Веб-приложение (SPA без зависимостей), которое помогает **правильно собрать персонажа в IdleArc** — под класс, уровень и цель игры. Все данные — снапшот официальных источников: сайт игры `idlearc.com` (включая официальные патч-ноты 1.3.1 «Season 2: The Forge» и страницу классов) и открытая IdleArc Wiki.

> Это неофициальный фанатский инструмент. Он не подключается к аккаунту игры, не автоматизирует геймплей и не требует логина.

## Что умеет

- **Планировщик сборки.** Выбираете класс (Warrior, Archer, Mage, Rogue, Druid), уровень и цель (прогресс, фарм, боссы, пет-билд, Retaliation) — приложение:
  - распределяет классовые очки с учётом правил игры (Tier 2 — после 5 очков в ветке, Tier 3 — после 10; 1 очко на 1 уровне + 1 каждые 3 уровня);
  - учитывает **+All Class Skills** (Torch, Sage Diadem, легендарные петы) — он поднимает эффективные ранги навыков, даже выше максимума, если у эффекта нет своего капа;
  - показывает итоговые бонусы (AD%, крит, Double Hit/Damage, пет, фарм-статы) и предупреждения (например, что данные Druid официально не описаны);
  - выдаёт приоритет характеристик, наборы гемов по слотам, целевые Drop Bonuses, талисманы и состав петов;
  - экспортирует план текстом (для Discord) и кодом сборки, который можно передать другому игроку.
- **Калькуляторы.** Урон (крит >100% → Crit Damage, «полные сотни» Double Hit/Double Damage, Boss Damage, Shadow Echo), защита (софт-кап DR 95% / хард-кап 99%, минимум 1% урона), Retaliation (`Reflecting% × Defense`, блок +50%), значение гема, стоимость Mastery, компоунд петов, классовые очки.
- **Кодекс.** Аффиксы, Drop Bonuses (T2→T9), гемы и сокеты, семейства снаряжения с имплиситами T1→T6, талисманы и инскрипты, петы, статы и стойки, Mastery, ML-анлоки, биомы, Convergence, гильдия, смена класса.
- **Нюансы и источники.** Список ловушек билдостроения (капы, диминишинг Lucky, баланс компоунда петов, `Slayer's` только для боссов и т.д.) + список источников и явная маркировка «подтверждено / требует проверки».

## Запуск

```bash
node server.js            # http://localhost:5173  (PORT=8080 node server.js — другой порт)
```

Сервер без зависимостей (только Node.js ≥ 18). Приложение — статика, поэтому подойдёт любой статический хостинг (GitHub Pages, Netlify, `python3 -m http.server`).

## Тесты

```bash
node tests/smoke.mjs
```

Смоук-тест прогоняет рендер всех вкладок через лёгкий DOM-шим, проверяет планировщик по 5 классам × 5 целям × 5 уровням и все формулы (крит >100%, DR-капы, Retaliation, гемы, компоунд петов, Mastery, коды сборок).

## Структура

```
index.html                 — каркас SPA и вкладки
server.js                  — статический сервер без зависимостей
styles/app.css             — тёмная тема в стиле игры (цвета редкостей из Item Codex)
src/app.js                 — роутинг вкладок
src/data/classes.js        — 5 классов, все классовые навыки: значения за очко, капы, требования
src/data/items.js          — редкости, аффиксы, Drop Bonuses T2–T9, гемы, слоты, имплиситы, тиры
src/data/systems.js        — статы, атрибуты, стойки, Mastery, петы, талисманы, руны, гильдия, прогрессия
src/data/builds.js         — профили рекомендаций (стойки, приоритеты статов, веса навыков) + чек-лист
src/core/calc.js           — формулы игры и модели расчёта
src/core/planner.js        — распределение очков и сборка плана, экспорт/импорт кодов
src/ui/*.js                — экраны: планировщик, калькуляторы, кодекс, нюансы
docs/RESEARCH.md           — конспект исследования официальных источников и выводы
tests/smoke.mjs            — смоук-тесты
```

## Источники данных

- Официальные классы и скилл-деревья — <https://idlearc.com/classes>

- IdleArc Wiki (сообщество) — <https://idlearc.fandom.com/wiki/IdleArc_Wiki>, включая официально одобренный гайд [Season 2 Progression & Strategy Guide](https://idlearc.fandom.com/wiki/Guide:Season_2_Progression_%26_Strategy_Guide)

Снапшот: **04.10.2026, версия игры 1.3.1 (Season 2)**. Игра обновляется часто, поэтому цифры стоит перепроверять после патчей.

## Что подтверждено, а что нет

- **Подтверждено официально:** правила очков и тиров, названия и значения большинства классовых навыков, аффиксы и их роллы, Drop Bonuses T2–T9, гемы (формула и таблицы), петы (шансы, pity, капы компоунда), талисманы, Mastery, ML-анлоки, Convergence, Guild Skill Tree, изменения патча 1.3.1.
- **Требует проверки в игре:** эффекты 18 навыков Druid (официально опубликованы только названия), новый воинский навык `Counterstrike` (заменил Victory Rush), точные прибавки Defense от навыков Warrior после реворка 1.3.1.
- **Модель, а не официальная формула:** расчёт ожидаемого множителя удара. Порядок слоёв урона игра не раскрывает, поэтому цифры годятся для сравнения вариантов, но не как точный DPS.
