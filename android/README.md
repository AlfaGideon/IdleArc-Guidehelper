# IdleArc Guide для Android

Неофициальная оболочка: вкладка **Игра** открывает оригинальный `https://idlearc.com/` в Android WebView; **Справочник** содержит офлайн-копию `hub/companion` (включается в APK при сборке); **Анализ** показывает только распознанные числовые показатели с текущей открытой страницы игры. Для игры нужен интернет и Android System WebView. Для справочника интернет не нужен.

## Сборка и установка

Требуются JDK 17, Android SDK (platforms;android-35 и build-tools), Gradle 8.10.2. Из папки `android`:

```sh
gradle :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или запустите workflow **Android APK** в GitHub Actions и скачайте артефакт `IdleArc-Guide-debug-apk`. Debug APK подписывается стандартным тестовым ключом; **не публикуйте его как релиз**. Для распространения нужен собственный release keystore и подпись.

## Границы анализа и безопасность

Это не модификация игры: приложению не доступны серверные данные, внутренние запросы приложения/игры, чужие вкладки или APK игры. Анализатор раз в 5 секунд берёт **только указанные числовые поля** из видимого текста DOM открытой страницы в WebView; он не читает пароли, cookie или содержимое сетевого трафика, не отправляет снимки и не ведёт историю. Набор полей и регулярные выражения — `Probe.java`; в зависимости от UI сайта показатели могут не обнаружиться или быть неточными. Код не автоматизирует нажатия, игру и авторизацию. Ссылки вне домена игры открываются во внешнем браузере; некоторые внешние способы входа могут не вернуться в WebView. Справочник — снимок данных из репозитория, а не живые данные аккаунта. Используйте только в соответствии с правилами IdleArc.
